## DeepSeek++ 1.13.1

1.13.1 是内联智能体体验打磨与对话导出稳定化版本：内联智能体的输出渲染与原生 Markdown 一致、工具状态展示更真实，对话导出的 HTML 格式与下载链路更可靠。

### 主要变化

- **内联智能体渲染修复**：Agent 输出改为与原生 Markdown 渲染一致的紧凑块级排版；剥离工具调用后的多余空行自动折叠，标题层级与正文对齐。
- **内联智能体 UI/UX 打磨**：工具执行状态如实展示（成功/失败/进行中），流式输出滚动更安全，暂停时显示中性页脚；图标改为 SVG 并统一类型与圆角体系，交互反馈更即时，键盘与读屏无障碍更好；启动失败不再无声。
- **对话导出稳定化**：HTML 导出包含输入/产出的统计信息，导出与下载链路更稳定，下载管理更可靠。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。
