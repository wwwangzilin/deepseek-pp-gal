# DeepSeek++ GAL 版 1.15.0

GAL 酒馆版首个独立版本：在 DeepSeek++（v1.14.0 上游）全功能基础上，集成 GAL 角色扮演舞台与 DSH 式角色模式。

## ✨ GAL 酒馆舞台

- 叠加在 DeepSeek 网页版上的 Galgame 舞台：立绘 + 背景 + 对话框 + 打字机/分页效果。
- 角色卡系统：内置「DeepSeek娘」与「雪璃」预设，可新建/编辑/删除角色，支持自定义立绘、角色名、颜色、开场白。
- 「🎭 选模式」：新对话前像选择角色模式一样一键载入角色设定与相关记忆。
- 自动识别角色扮演设定请求，一键把设定保存为可复用模式卡。
- 思考过程与正式回复分离展示（思考态以「思考中」动画呈现，正文走打字机分页）。

## 🎭 DSH 式角色模式（记忆跟着角色走）

- 记忆新增「角色」归属维度：每条记忆要么是**全局共享**（所有角色可见），要么**只属于某个角色**（仅该角色激活时注入）。
- 激活角色后，对话中模型自动沉淀的记忆**自动归属当前角色**，切换角色互不串味。
- 角色卡内置「🧠 记忆」管理面板：查看该角色记忆、手动添加、设为全局、删除。
- 切换角色时自动开新会话（会话级隔离），旧角色的对话历史不会泄漏给新角色。

## ⚙️ 默认原版界面 + 一键开关

- 默认保持 DeepSeek 原版界面，不再自动覆盖；需要时点页面右下角「🎭 GAL 酒馆」开启，选择会被记住。
- 舞台右上角「⏻ 关闭 GAL」随时回到原版，刷新后保持上次选择。

## 🔧 工程

- 注入节奏开关：角色卡面板可设置「每条消息都注入角色提示词」（角色始终在场）或仅首条注入。
- 修复角色设定记忆落库失败的兼容性问题。
- 版本号对齐 release 流程（package.json / shell-host 同步 v1.15.0）。

> 基础能力继承自上游 DeepSeek++：Agentic 记忆、Skill、MCP、自动化、项目上下文、对话导出、保存项、网络工具、离线沙箱（Python/Shell）等。本 fork 不发布 npm 包（`deepseek-pp-shell-host` 沿用上游版本）。
