## DeepSeek++ 1.11.9

1.11.9 是一次聊天与 MCP 使用体验更新，修复编辑消息后的上下文注入、输出速度统计、输入法回车和 MCP 工具选择等问题，并让 DeepSeek 原生智能搜索与扩展工具更好地协同。

### 主要变化

- **编辑消息后上下文恢复**：编辑 DeepSeek 消息后，扩展注入的记忆、预设和工具提示会像新消息一样继续生效，不再丢失。
- **输出速度统计更准确**：模型输出速度只统计可见输出，不再把隐藏思考文本计入，避免数字虚高。
- **输入法回车不再误提交**：使用中文等输入法组合输入时，按回车选择候选词不会提前发送消息。
- **MCP 兼容性与工具选择**：改善与使用标准流式格式的 MCP 服务的兼容性；手动模式下工具选择状态保持清晰可选，明确区分自动、已选和禁用，切换工具不会清空已发现的服务信息。
- **原生搜索与工具协同**：使用 DeepSeek 原生智能搜索时，普通对话和 Agent 续跑会继续使用原生搜索，不再重复触发扩展自带的联网搜索，其他工具不受影响。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。

English:

- Fixes edited DeepSeek messages losing the extension's prompt and context, and premature message submission while confirming IME composition candidates.
- Model output speed statistics no longer count hidden reasoning text and now reflect visible output more accurately.
- Improves MCP streaming compatibility and manual tool selection, so switching tools no longer clears discovered service information.
- Keeps DeepSeek native intelligent search active for regular and agent-continuation requests without triggering a duplicate built-in web search.
