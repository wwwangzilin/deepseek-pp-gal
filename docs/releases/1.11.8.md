## DeepSeek++ 1.11.8

1.11.8 是一次可选云同步可靠性更新，减少同步服务暂时繁忙时个别数据文件上传或下载失败的情况。

### 主要变化

- **上传更稳定**：同步上传会有序处理数据文件，降低服务临时限制并发请求时出现单个文件失败的概率。
- **下载更稳定**：同步下载同样会有序读取文件，减少个别保存项或其他同步数据在服务繁忙时无法下载的情况。
- **完整性保持不变**：只有一份完整同步数据全部通过长度和校验验证后，才会更新本地记忆、Skill、预设、项目和保存项。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。

### Chrome Web Store 更新说明

中文：

- 改善可选云同步的上传和下载稳定性，减少同步服务暂时繁忙时个别数据文件失败的情况。
- 同步数据会在完整下载并通过校验后再更新本地内容，降低不完整同步带来的困扰。

English:

- Improves optional cloud-sync upload and download reliability when a sync service is temporarily busy.
- Synced data updates locally only after the complete dataset has downloaded and passed validation.
- The Chrome package adds no new browser permissions.
