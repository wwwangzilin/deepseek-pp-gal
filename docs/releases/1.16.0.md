# DeepSeek++ GAL 版 1.16.0

角色模式全面并入 DeepSeek++：角色成为一等公民，AI 能自己建角色，多角色成为"群组"。

## 🎭 角色体系（并入 DeepSeek++ 界面）

- **独立「角色」页**：侧边栏顶层新增，角色列表 / 新建 / 编辑 / 设为当前 / 停用 / 删除，含立绘、主题色、设定、性格、场景、示例对话、开场白、附加指令、记忆关键词。
- **独立角色存储**：角色不再占用系统提示词预设——激活角色与你的预设互不覆盖；角色在场注入角色人格，退出自动回到原预设。
- **角色记忆隔离**：每个角色独立记忆空间（全局共享 + 角色专属），模型自动沉淀的记忆归属当前角色。
- **角色卡导入导出**：兼容 SillyTavern PNG 角色卡（V1/V2/V3，`chara`/`ccv3`），一键导入/导出，直接吃现成角色卡生态。
- **角色日记**：把角色记忆与群聊事件合成时间线，日记式回看与角色的经历。

## 🤖 AI 自己建角色

- 新工具 `gal_character_upsert`：对话里说「你扮演 XX…」，模型自己把设定整理成角色卡存库；同名角色会被更新（随对话成长），保存后即可在舞台/角色页选用。

## 👥 群组联动（借用项目做共享上下文）

- 侧边栏「角色 → 群组」：建群、选成员；系统自动为群组创建共享项目。
- GAL 舞台顶栏「👥 群组」：进入群组、**勾选本轮发言者**（可多选或「全选依次发言」）→ 成员按顺序各自以自己的人格发言；不勾选即单角色私聊。
- 每轮发言自动沉淀进**群组共享记忆**（项目维度），成员之间因此"听得见"彼此；群聊会话自动挂到群组项目。
- **群聊多立绘同框**：群组激活时成员立绘并排站位，当前发言者高亮、其余降饱和。

## ❤️ 好感度

- 每个角色有 0-100 好感度，对话中自然增长；人格注入会带上关系分档（刚认识 → 亲近 → 恋人般亲密），语气随之变化；舞台名牌/角色卡/群组列表显示 ❤️，角色页可手动调整。

## 💾 剧情存档 / 💭 角色主动消息

- **剧情存档**：舞台「💾 存档」保存剧情点（舞台剧情 + 角色/群组/发言者状态），随时读档回看（服务端会话历史不回滚）。
- **主动消息**：设置 → 提示词可开启"空闲时角色主动搭话"，舞台打开且长时间无互动时角色会主动找你说话（默认关闭，消耗 API 额度）。

## 🔧 工具调用界面

- 舞台新增工具执行状态胶囊：执行中显示「🔧 联网搜索 · 记忆保存 执行中…」（带转圈），完成显示「✓ 工具执行完成：…」并淡出，失败标 ⚠️；工具名中文化。
- 台词不再混入工具卡片：读回复时剥离 deepseek-pp 的工具/产物块，对话框只留对白。

## ⚙️ 其它

- GAL 设置（默认开关、角色注入节奏、主动消息）全部并入「设置 → 提示词」；GAL 舞台默认关闭，右下角一键开启并记住选择。
- 旧版 localStorage 角色卡与开关状态首次加载自动迁移进扩展存储。

> 基础能力继承自上游 DeepSeek++ 1.14/1.15：记忆、Skill、MCP、自动化、项目、对话导出、沙箱执行等。
