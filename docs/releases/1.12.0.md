## DeepSeek++ 1.12.0

1.12.0 是 Agent 工作台与文件引用体验更新，让内联智能体运行更可靠、步骤清晰可见，并支持在聊天中通过 @ 引用可信目录中的文件。

### 主要变化

- **结构化 Agent 步骤界面**：Agent 运行时展示清晰的步骤与全局运行指示，循环结束不再无声无息，重复步骤有重试上限，避免无限循环；窗口类工具（如浏览器控制）的结果按窗口展示，续跑提示更准确。
- **原生搜索协调**：Agent 使用 DeepSeek 原生智能搜索时，不再触发扩展自带的联网搜索工具，避免重复搜索。
- **可信目录与 @ 文件引用**：新增“项目文件”设置页，可选择带扫描预算的本地可信目录；在聊天中用 @ 打开引用面板，把目录中的图片送入对话。只在你选择并保存的目录内生效，路径越界的内容会被忽略。
- **文件引用健壮性**：图片 MIME 规范化避免同一图片重复上传；扩展上下文失效（如重载扩展后旧页面残留）时不再误报记忆保存失败。
- **用量图表修正**：30 天 Token 趋势图 X 轴只显示日期，标签不再挤出图表面板。
- **MCP 兼容性**：MCP 客户端能力声明改为符合协议规范的有效值，与校验客户端能力的服务端连接更稳定。
- **页面加载清理**：扩展页面不再输出 modulepreload 预加载链接，消除浏览器控制台中的相关噪音。
- **权限变化**：Chrome、Edge 和 Firefox 均不新增浏览器权限。

### Chrome Web Store 更新说明

中文：

- 内联智能体运行更可靠：新增结构化步骤界面与全局运行指示，循环结束可见、重复步骤有重试上限，使用 DeepSeek 原生智能搜索时不再重复触发扩展自带联网搜索。
- 新增可信目录与 @ 文件引用：在设置中选择一个本地目录后，可在聊天中用 @ 引用目录中的图片；只在你选择的目录内生效，越界内容会被忽略。
- 修复 30 天 Token 趋势图 X 轴溢出，以及扩展上下文失效时误报保存失败的问题；改善与部分 MCP 服务的兼容性。
- Chrome 版本不新增浏览器权限。

English:

- Agent runs are more reliable: structured step UI with a global running indicator, visible loop endings, bounded step retries, and no duplicate built-in web search when DeepSeek native intelligent search is active.
- New trusted directory and @ file references: after choosing a local directory in Settings, you can reference images from it in chat with @; only your chosen directory is scanned and out-of-bounds paths are ignored.
- Fixes the 30-day token trend X-axis overflow and false save-failure reports after an extension context becomes invalid; improves compatibility with some MCP services.
- The Chrome package adds no new browser permissions.
